# NameCrit Suggestions

This is the public suggestion board for [namecrit.com](https://namecrit.com) —
game-specific character name generators, built per game from its actual lore.

**Want a generator for a game we haven't covered?** Open a Discussion (or add a
👍 to an existing one — reactions are votes, and enough votes genuinely moves a
game up the build queue).

**Got an idea that would make the generators better?** Same place. Ideas that
change how we build get shipped and credited, permanently, on our
[changelog](https://namecrit.com/how-its-made/).

House rules: keep it civil, no spam, and pedantry about lore accuracy is —
on this board alone — a virtue.

*This repo holds no code; the site lives elsewhere. Discussions here are
embedded on namecrit.com via [giscus](https://giscus.app).*
